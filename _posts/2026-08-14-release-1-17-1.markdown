## Fixes and enhancements for devices with FEM
The ``radio.fem.rxgain`` setting was not being persisted properly in v1.17.0, this is now fixed. Repeater admins will want to check that ``radio.fem.rxgain`` and ``radio.rxgain`` are configured to their liking after updating.
Companion firmware currently has no way to configure these settings, so they they will use the default values only for now.

## Heltec T096 Transmit issue fix
The Heltec T096 transmit issue was found to be an out of bounds read of the pin map due to ``PIN_SPI1_MISO`` being set to -1. It was causing the FEM's Tx enable pin to stop working. This has been fixed and other NRF52 boards have had their unused pins corrected.
